# trip-plan

从零生成一份**能照着走**的旅行行程报告。**零大模型依赖**，纯本地规则引擎。

输入「出发地 + 目的地 + 天数 + 出发日期」，输出一份带**路线图、逐日动线、天气装备、
约票提醒、费用区间、住宿推荐、风险清单**的单文件 HTML 报告。

---

## 一、30 秒上手

### Windows：双击 BAT

| 双击 | 作用 |
|---|---|
| **`运行.bat`** | 单目的地一键出报告（检索 → 编排 → 出报告，约 30 秒） |
| **`生成地图.bat`** | 出路线图 / 把地图内嵌进报告 |
| **`住宿层.bat`** | 抓真实住宿点位 + 出「首选 / 升级 / 特色 / 预算」四档推荐 |
| **`快速重排.bat`** | 改天数 / 日期快速重跑（复用已检索数据，不重新联网） |
| **`打包.bat`** | 打成一个可以搬到别的电脑的 zip |

BAT 自带 Python 探测（WorkBuddy 自带解释器 → PATH 里的 `python`/`py` → 常见安装路径），
**不用配环境变量**。中文 GBK 编码，中文 Windows 双击即用。

### 命令行（Windows / macOS / Linux 通用）

```bash
python scripts/pipeline.py \
  --origin 上海 --city 绍兴 \
  --days 5 --start 2026-10-01 \
  --out ./out
```

产物都在 `out/`：

| 文件 | 内容 |
|---|---|
| `graded.json` | 检索结果 + 信源分级明细（A/U/C/D） |
| `places.json` | 抽取出的景点池（含坐标、票价、时长） |
| `itinerary.json` | 逐日行程（含坐标、预算、备选） |
| `报告_*.md` | 人读报告（模块标记 + `<details>` 折叠） |
| `报告_*.html` | **模块化单文件 HTML**，含内嵌 SVG 路线图 |

## 二、搬到别的电脑 / 发到手机

### 搬到别的电脑

1. **拷整个 `trip-plan/` 目录过去**（或解压 zip）。
   ⚠ **不要把 `scripts/` 里的文件单独拿出来** —— 它们互相 `import`，必须整目录在一起。
2. 装 **Python 3.8+**。
3. Windows 直接双击 BAT；其他系统走上面的命令行。
4. 只有需要「Markdown → HTML」时，才需要装唯一的第三方依赖：

   ```bash
   pip install -r requirements.txt     # 只有 markdown 一个包
   ```

   **不装也能跑** —— `pipeline.py` 会自动退回内置轻量转换器
   （报告能出，只是没有模块导航、不折细节、不含路线地图），并在日志里提示。

> 脚本里**没有任何绝对路径硬编码**，`sys.path` 一律基于 `__file__` 自解析，
> 所以整个目录放在任何位置都能直接跑。

### 手机上

**手机不能跑这套脚本**（要 Python 运行环境 + 联网检索），但**成果可以在手机上看** ——
这也正是地图默认做成**内联 SVG** 的原因：

| 产物 | 手机上 | 怎么发过去 |
|---|---|---|
| `报告_*.html` | ✅ 单文件、离线可读 | 微信 / 邮件 / 网盘，点开即看 |
| 独立 SVG 路线图（`生成地图.bat` 选项 1） | ✅ 零外部依赖、可双指缩放、可打印 | 同上 |
| `报告_*.md` | ✅ 任意笔记 / 文档 App | 同上 |
| `map_腾讯交互版.html` | ❌ **必然空白** | 底图走 WorkBuddy 代理，只能在本工具预览面板看 |

**结论：分享给别人 / 发到手机，一律用「报告 HTML」或「独立 SVG 地图」。**

## 三、报告长什么样

以「上海 → 绍兴 5 天」为例（`example/报告示例.html` 是完整成品，可直接打开看）：

```
D1 10-01 [古城北 + 古城核心] 鲁迅故里 → 书圣故里 → 仓桥直街 → 沈园
D2 10-02 [古城北 + 城东 + 城南] 八字桥 → 黄酒小镇 → 东湖 → 大禹陵
D3 10-03 [兰亭 + 柯桥 + 鉴湖柯岩] 安昌古镇 → 柯岩风景区 → 柯桥古镇 → 兰亭
D4 10-04 [古城北] 周恩来纪念馆 → 蔡元培故居 → 迎恩门风情水街 → 秋瑾故居
D5 10-05 [古城核心 + 古城西] 府山公园 → 大善塔 → 绍兴博物馆新馆 → 塔山

门票 340 元（23 个免费景点） | 单日最大跨度 ≤ 15.4 km
```

报告是**模块化版面**（顶部导航切换，不是一页到底）。单目的地典型 9 个模块：

> 概览 / 详细行程 / 城际交通 / 预约与限流 / 备选地点 / 费用 / **路线地图** / 行前与风险 / 信源与核查

境外或多片区会再补 **天气与装备 / 近期动向 / 拥挤度与错峰**，最多 10~11 个模块。

**排版规矩**：结论入正文，论据进折叠。长表（全部景点门票、完整住宿候选池）
和 A 级信源清单都折进 `<details>`，点开才看 —— 正文永远是结论。

**路线图默认是内联 SVG 两层分面示意图**：每天一格，格内若出现相距很远的片区会再拆子格，
各自带比例尺。零外部依赖、免 Key、断网可渲染、静态托管不白屏、可直接打印。

## 四、它是怎么工作的

```
检索 ────→ 分级 ────→ 抽取 ────→ 编排 ────→ 报告
anysearch  A/U/C/D    规则引擎    规则引擎    MD + 单文件 HTML
匿名可用   域名判定   景点识别    地理聚类    + 内联 SVG 路线图
```

四个关键设计：

1. **信源分四级**：A（权威媒体 / 政府官网 / 官方票务）直接采信，U（真实 UGC 笔记页）
   交叉印证，C（境外 OTA / 旧帖）标注核对，D（地域无关）直接排除。报告末附 A 级信源链接可复核。

2. **规则引擎抽取景点**：四层过滤（后缀严格判定 + 句式排除 + 繁简统一 + 白名单）。
   实测从 104 条检索结果里抽出 59 个干净景点，剔除"级景区""白天走老街"这类碎片。

3. **四阶段地理编排**（核心）：
   - 名片保底 —— 城市必去景点无条件入选，不靠打分
   - 片区配额 —— 按"价值密度"给片区预留天数
   - 配额执行 —— 高密度片区先挑天，优先与同片区成组
   - 全局补位 —— 剩余容量按分数填，受"每天 ≤ N 个 + 单日跨度上限"双约束

4. **远郊自动降级**：离城 > 45 km 的名片转入"一日游备选"。
   单程 1.5 小时以上当天往返会挤掉市区体验 —— 这是产品决策，跑更多天时它会自动回归。

### 额外六个层（按需启用）

| 层 | 脚本 | 做什么 |
|---|---|---|
| **补查询** | `gapfill.py` | 八方向缺口检测（闭园维修 / 预约限流 / 交通管制 / 新开试运营 / 季节限定 / 票价变动 / 避坑 / 船班），定向补查，带相关性闸门，最多两轮 |
| **天气** | `weather.py` | Open-Meteo 免 Key。出行日临近用预报；超窗口（如提前一年订票）用过往 5 年同期做气候平均，给穿衣 / 带伞 / 防晒 / 大风建议与雨天对调方案 |
| **拥挤度** | `crowd_research.py` + `digest_crowd.py` | 针对小长假 / 暑期逐个景点研判拥挤程度、峰值时段与错峰建议 |
| **住宿** | `lodging.py` | 两个 provider（Overpass 免 Key / 高德需免费 Key）；出「首选 / 升级 / 特色 / 预算」四档 + 价格档位。**价格是区间不是实时报价** |
| **地图** | `map_html.py` | `--mode svg` 零依赖离线版（默认推荐）；`--mode tmap` 腾讯交互版（只能在本工具预览面板看） |
| **境外** | `overseas_research.py` | Photon 地理编码 + Overpass POI + OSRM 真实路网 + OpenFreeMap 底图，全是免 Key 开源栈 |

## 五、住宿层（2026-09 新增）

**先说结论**：酒店**点位**能免费拿到，酒店**房价**没有任何免费开放接口。

| 数据源 | 可达性 | 结论 |
|---|---|---|
| **OSM Overpass** | ✅ 免 Key，全球可用 | **唯一开箱即用**；含名称 / 类型 / 星级 / 房量 / 官网 / 电话 |
| **高德 Web 服务 POI** | ✅ 可达（需自申请免费 Key） | **国内覆盖最好**，含评分与人均消费 |
| 百度 / 腾讯位置服务 / 天地图 | ✅ 可达（各需自申请 Key） | 同量级备选 |
| 携程 / 飞猪 / 去哪儿 / 美团**开放平台** | ✅ 站点可达 | **全是商户入驻门户**，要企业资质，无匿名数据接口 |
| Booking / Expedia / Amadeus / Hostelworld | ❌ 401 / 403 / 连不通 | 需企业签约，非开放接口 |

所以本层**只输出档位区间**，报告里强制标注"非实时报价、下单前须复核"。
**不会为了让报告好看而伪造精确房价。**

```bash
python scripts/lodging.py fetch --stays stays.json --out lodging.json          # Overpass
python scripts/lodging.py fetch --stays stays.json --provider amap \
       --amap-key <Key> --out lodging.json                                     # 高德
python scripts/lodging.py pick  --lodging lodging.json --out hotel_plan.json --currency CNY
```

`stays.json` 从 `itinerary.json` 的住宿锚点派生，格式见 `stays.example.json`。

## 七、常见问题

**Q：双击 BAT 提示「未找到 Python」。**
装 Python 3.8+，安装时勾选 **Add Python to PATH**。装完重开 BAT 即可。

**Q：报告出来了，但没有路线地图。**
两种原因：① 没装 `markdown`（`pip install -r requirements.txt`）；
② 行程里的景点缺经纬度（单目的地模式依赖 `planner.py` 的 `KNOWN_COORDS` 表，
未收录的景点会落到"未定位"并进备选）。补坐标即可。

**Q：HTML 打开是白屏。**
只有**腾讯交互版**（`--map-mode tmap`）会白屏 —— 它的底图靠 WorkBuddy 运行时注入代理端口，
脱机或换环境必然空白。**默认的 SVG 版不会白屏**。交付一律用 SVG。

**Q：`md2html.py` 报 `ModuleNotFoundError: No module named 'markdown'`。**
`pip install markdown`。这是唯一的外部依赖。
（新版已改成友好提示，并让 `pipeline.py` 自动降级，不会中断整个流程。）

**Q：报告里的价格准吗？**
门票来自检索到的公开信息，标注信源等级；**住宿价格是档位区间，不是实时报价**。
境外自驾还要注意：**油费口径已变** —— 冰岛自 2026 年起以「里程税」取代燃油税
（3.5 吨以下 6.95 ISK/km），费用表必须把里程税单列，
否则会漏算约 ¥800/车。**「Unlimited Mileage（不限里程）」不等于已含公里税。**

**Q：想换目的地。**
算法层通用，改三张表即可（都在 `scripts/planner.py`）：
`CITY_CENTER`（必改）/ `REGIONS` / `KNOWN_COORDS` / `MUST_SEE`。
坐标用 **GCJ-02**。详细步骤见 `references/换城市指南.md`。

## 九、为什么不用大模型

行程规划的瓶颈是**数据质量**和**地理约束**，不是语言理解：

- 判断"这条来自权威媒体还是三年前的论坛帖" —— 规则比模型稳定
- 保证"同天景点 ≤ 18 km" —— 确定性计算，模型反而容易算错

规则引擎的收益：可复现（同输入同输出）、可调试（每个决策有中间变量）、
零成本、离线可跑、编排耗时 < 1 秒。

**模型适合插入的位置是抽取层**（处理"离鲁迅故里两站路的那个老台门"这类非标准表述）。
`places.json` 的格式与模型输入一致，替换是局部的、不影响其他环节。
